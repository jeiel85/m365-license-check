계정 페이지엔 Microsoft 365가 그대로 있는데 Office만 막혔다면, 이 PC에 남은 라이선스 캐시가 낡았을 가능성이 큽니다. 명령 한 줄로 확인하고, 원하면 캐시를 새로 받습니다.

Windows PowerShell
PS> irm https://raw.githubusercontent.com/jeiel85/m365-license-check/main/m365-license-check.cmd | iex

m365-license-check v1.0.0 - Microsoft 365 Office 라이선스 진단

== 구독 라이선스 ==

Product : O365HomePremRetail

LicenseState : Licensed

EntitlementStatus : Provisioned

== 판정 ==

이상 없음: 구독 라이선스가 정상(Licensed / Provisioned)입니다.

라이선스 캐시를 백업 후 초기화할까요? [y/N]

캐시를 새로 받은 뒤 실제 실행 화면

  1. 명령 복사를 누르고
  2. Win+X → 터미널을 연 뒤
  3. 붙여넣고 Enter

명령어가 낯설다면 파일로 받아 더블클릭

● 아무것도 바꾸지 않음

진단

  • 설치된 Office가 구독용인지
  • 로그인된 계정이 여러 개인지
  • 구독 라이선스 상태와 만료일 — Office에 들어 있는 Microsoft 도구 vnextdiag로 읽습니다
● 물어본 뒤에만

캐시 초기화

  • 열린 Office 앱을 닫습니다. 강제 종료는 따로 묻습니다
  • 라이선스 캐시를 백업한 뒤 지웁니다
  • Word가 열리면 로그인 → Enter로 바로 다시 진단

로그인 정보는 그대로 두고, 어떤 데이터도 밖으로 보내지 않습니다. 관리자 권한도 필요 없습니다.

자주 묻는
질문

OneDrive는 되는데 왜 Word만 막히나요?

OneDrive는 구독이 없어도 무료 5GB로 동작합니다. Office는 PC에 받아 둔 라이선스 파일을 따로 보기 때문에, OneDrive가 된다고 Office 라이선스가 정상이라는 뜻은 아닙니다.

회사 IT 관리자에게 요청해야 하나요?

개인·Family 구독에는 IT 관리자가 없습니다. 초기화하고 다시 로그인해도 "취소"로 나오면, Family 구독을 공유해 준 소유자가 account.microsoft.com/services에서 정기 결제 해제·결제 실패·공유 목록 제외 여부를 확인해야 합니다. 회사·학교 계정은 이 도구의 대상이 아니니 조직 관리자에게 문의하세요.

초기화하면 문서나 설정이 사라지나요?

아니요. 지우는 것은 라이선스 캐시(%LOCALAPPDATA%\Microsoft\Office\Licenses, 레지스트리 …\Office\16.0\Common\Licensing)뿐이고, 지우기 전에 백업합니다. 백업 위치와 되돌리는 방법을 화면에 알려 줍니다.

인터넷에서 받은 스크립트를 실행해도 되나요?

실행 전에 소스 전체를 읽어 보세요. 파일 하나뿐입니다. 내려받은 파일을 실행하면 서명되지 않은 스크립트라서 Windows가 경고를 띄울 수 있습니다.
